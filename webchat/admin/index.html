Webchat Admin

Panduan Menghubungkan AI Chatbot ke Website

  1. Daftarkan website di form "Tambah Website Baru" di bawah ini.
    Isi Nama Website (wajib), Domain (opsional, untuk catatan saja), dan System Prompt (instruksi untuk AI — tulis semua info tentang bisnis/website kamu di sini, karena AI hanya tahu apa yang kamu tulis).

    Contoh System Prompt:
    "Kamu adalah asisten Toko Sepatu XYZ. Produk: Nike Air Max (Rp 1.5jt), Adidas Ultraboost (Rp 2jt). Jam buka: Senin-Sabtu 09:00-21:00. Kontak WA: 08123456789."

  2. Setelah berhasil, akan muncul kode script embed. Klik tombol "Salin Kode" untuk menyalin. Kalau lupa, kamu bisa klik tombol "Script" di tabel Website Terdaftar kapan saja (butuh verifikasi Admin Token).
  3. Untuk website HTML biasa: Buka file HTML utama (misal index.html). Tempel kode script tepat sebelum tag </body> (baris terakhir sebelum body ditutup).
    <!-- File: index.html --> <body> <!-- ... isi halaman website kamu ... --> <h1>Selamat Datang</h1> <p>Konten website kamu di sini.</p> <!-- TEMPEL KODE INI DI SINI (sebelum </body>) --> <script src="https://BACKEND_URL/widget/chat-widget.js" data-widget-key="WIDGET_KEY_KAMU" data-api-url="https://BACKEND_URL/api/chat"></script> </body> </html>

    Ganti BACKEND_URL dengan URL backend kamu (misal https://chat.domainmu.com) dan WIDGET_KEY_KAMU dengan widget key dari hasil pendaftaran.

  4. Untuk Next.js (App Router): Buka file src/app/layout.tsx. Tambahkan import di bagian atas file, lalu tempel komponen <Script> di dalam <body> setelah konten terakhir, sebelum </body>.
    // File: src/app/layout.tsx // Tambahkan import ini di bagian atas (bersama import lain): import Script from "next/script"; // Lalu di dalam return, taruh <Script> sebelum </body>: <body className="..."> <!-- komponen-komponen kamu --> <SmoothScrollProvider> {children} </SmoothScrollProvider> {/* TEMPEL DI SINI (sebelum </body>) */} <Script src="https://BACKEND_URL/widget/chat-widget.js" data-widget-key="WIDGET_KEY_KAMU" data-api-url="https://BACKEND_URL/api/chat" strategy="afterInteractive" /> </body>

    strategy="afterInteractive" membuat script dijalankan setelah halaman siap, supaya tidak memperlambat loading website.

  5. Simpan file, deploy/refresh website. Bubble chat (lingkaran emas) akan muncul di pojok kanan bawah. Klik untuk mulai chat dengan AI.
  6. Mau edit System Prompt atau info website nanti? Klik tombol "Edit" di tabel Website Terdaftar. Perubahan langsung berlaku tanpa perlu ganti kode embed.
Catatan penting:
• Selama backend masih di localhost:3001, chatbot hanya bisa diakses dari komputer kamu sendiri. Pengunjung lain tidak bisa menggunakannya. Supaya bisa diakses publik, deploy backend ke VPS/server dengan HTTPS (misal https://chat.domainmu.com), lalu ganti URL di kode script.
• Export Token bersifat RAHASIA. Dipakai untuk export riwayat chat ke CSV. Simpan baik-baik di tempat aman, jangan ditempel di kode website atau dibagikan ke publik.
• Widget Key bersifat publik (aman ditempel di kode website). Tapi Admin Token dan Export Token harus dirahasiakan.
