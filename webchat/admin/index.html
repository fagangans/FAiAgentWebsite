Webchat Admin

Panduan Menghubungkan AI Chatbot ke Website

  1. Daftarkan website di form "Tambah Website Baru" di bawah. Isi nama website dan System Prompt (instruksi karakter AI, contoh: "Kamu adalah asisten toko sepatu yang ramah"). Domain opsional.
  2. Setelah berhasil, akan muncul kode script. Klik tombol "Salin Kode" untuk menyalin.
  3. Buka file HTML utama website kamu. Cari tag </body> di bagian paling bawah.
  4. Tempel kode script tepat sebelum </body>. Contoh hasil:
    <script src=".../chat-widget.js" data-widget-key="..." data-api-url="..."></script>
    </body>
  5. Kalau pakai Next.js (React), buka src/app/layout.tsx, tambahkan import Script from "next/script", lalu tempel di dalam <body>:
    <Script src="..." data-widget-key="..." data-api-url="..." strategy="afterInteractive" />
  6. Simpan, deploy/refresh website. Bubble chat akan muncul di pojok kanan bawah. Klik untuk mulai chat dengan AI.
Catatan penting: Selama backend masih di localhost, chatbot hanya bisa diakses dari komputer kamu sendiri. Supaya bisa diakses publik oleh semua pengunjung, backend harus di-deploy ke VPS/server dengan domain HTTPS (misal https://chat.domainmu.com), lalu ganti URL di kode script dari localhost:3001 ke domain tersebut.

Export Token bersifat rahasia, dipakai untuk export riwayat chat ke CSV. Simpan baik-baik, jangan ditempel di kode website.
